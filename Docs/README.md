# Bifrost 首版文档
截至 2026-11-17，产品范围、技术栈和看板 UI 已确定。第 01 票可在临时 PostgreSQL 上运行[合成持仓演示](../README.md#运行最新持仓演示)；多账号手动采集见[合成工作区](../README.md#运行多账号工作区)。测试环境 Compose 部署流程见[部署指南](./部署指南.md)；生产部署、日终历史和收益仍是开发目标。

合理的第一项联调：用两个测试账号核对钱包余额与稳定身份，再核验美元行情源和同一账户的日终样例。真实汇率和账户模式对账是上线前条件；不完整的数据不得伪装成收益或零余额。
