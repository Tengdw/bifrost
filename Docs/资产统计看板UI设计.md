# Bifrost · 资产统计看板 UI 原型
日期：2026-11-17。打开[交互设计稿](../ui-preview/dist/index.html)可离线评审，也可查看[桌面预览图](../ui-preview/preview.png)。设计稿使用两个虚构账号，金额均为示例，不调用交易所。

| 区域 | 控件作用范围 | 展示口径 |
| --- | --- | --- |
| 顶部账户选择 | 整页 | 可在全部账号、主账号和策略账号间切换。 |
| 资产总值与收益表现 | 7、30、90 天控制收益摘要和曲线 | 总资产始终显示最近日终值。曲线切换资产走势、每日收益额、每日收益率。 |
| 日历 | 独立按月翻页 | 可切换每日盈亏和资产变化。日期格取整，点击显示精确到分的金额；未记录日期显示横线，不计为零。 |
| 美元资产分布 | 与主卡相同的最近日终估值、当前所选账号 | 原型默认按四个钱包展示，美股计入资金。首版接口另提供按资产类别的分布，其中美股单列；切换只改变分组，不改变主卡总额。bStocks 待验证。图例同时列出 USD 金额及份额；账号明细表可逐项核对。 |

UI 已确认（2026-11-17）。本原型演示美元视图，不假设 USDT 与 USD 等价。示例金额直接以美元给出；接真实数据时应在快照时间按实际汇率折算，并保留汇率及来源。

日界线按北京时间。资产变化 = 期末权益 − 期初权益；每日盈亏 = 资产变化 − 外部净流入。示例中外部资金流均在日初，日收益率 = 每日盈亏 ÷（期初权益 + 日初净流入），区间收益率由每日收益率复合而成。该简化前提不适用于任意时点的真实充提；正式接入按[资产口径与币安接口映射](./资产口径与币安接口映射.md)中的日内时间权重计算，缺价或流水不完整时不显示可靠收益率。
