# 资产口径与币安接口映射
首版实施约定 · 2026-11-17。看板使用 USD；币安返回的原币、原始计价单位和原始精度都要保留。下列响应是**合成的最小字段样例**，不是实盘数据。接口与字段以链接中的币安文档为依据，计算和降级规则是 Bifrost 的约定。

## 从四类钱包取什么

| 钱包 | 主读接口及粒度 | 进入权益的字段 | 仅展示或对账 |
|---|---|---|---|
| 现货 | [GET /api/v3/account](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#account-information-user_data)，balances 每币一行 | (free + locked) × 币价 | 挂单占用已在 locked 内 |
| 资金 | [POST /sapi/v1/asset/get-funding-asset](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/asset)，普通余额每币一行；这是查询。直接持股以同页的 GET /sapi/v1/asset/wallet/balance?needBalanceDetail=true 中 Funding.assetBalances 为准 | 分栏存 free、locked、freeze、withdrawing。适配器须先与同一时点钱包核实互斥，互斥时才相加；无法核实的非零栏标待对账 | btcValuation 及 GET /sapi/v1/asset/wallet/balance 的钱包汇总均不二次累加 |
| 赚币 | [GET /sapi/v1/simple-earn/flexible/position 与 /sapi/v1/simple-earn/locked/position](https://developers.binance.com/en/docs/catalog/investment-and-services-simple-earn/api/rest-api/flexible-locked)，两路分别翻完所有页 | 活期按 productId 的 totalAmount；定期按 positionId 的当前持仓 amount。HOLDING 以外状态、赎回在途或抵押有跨钱包重叠时须对账；归属不明则标部分数据 | rewardAmt、累计奖励、collateralAmount、redeemingAmt 不额外叠加；不计预计利息 |
| 普通 U 本位 | [GET /fapi/v3/account 与账户配置](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account)；[GET /fapi/v3/positionRisk](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/trade) 单列仓位 | 单资产模式按各结算资产 assets[].marginBalance 折 USD 后求和，不能以单资产模式的 USDT 顶层值代表其他结算币。联合保证金按接口 USD 汇总权益 totalMarginBalance 计一次，保存模式和原单位 | walletBalance、unrealizedProfit 用于核对；availableBalance、notional、逐仓占用、逐仓浮盈不再加。统一账户标范围外 |

拒绝用 API 失败推断零余额。对账按相同账号、钱包、单位和接近的采集时点比较；产品模式或新字段不认识时保留原值与原因，停止把该项标为完整。

### 币安直接持股：先确定钱包归属，再按资产类别分组
2026-11-17 的只读核对在 `walletName=Funding` 的 `assetBalances[].asset` 中观察到非零的 `EQ_MU` 和 `EQ_NVDA`，对应股票成交的 `MU` 和 `NVDA`。这是已验证的返回形式；样本不代表所有账号、所有证券都必然沿用此前缀。

| 只读来源 | Bifrost 处理 |
|---|---|
| [钱包余额明细](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/asset) + [GET /sapi/v1/equity/market/exchangeInfo](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/market-data) | 读取 Funding 的 `EQ_<symbol>`，保留原始代码，去前缀后按完整 symbol 核对股票目录。命中才标 `wallet=funding, assetClass=us_equity`；普通加密币即使与美股同名也不归类为股票。目录缺失或不匹配标待核对，不丢弃数量；未返回 assetBalances 不能推断持股为零。 |
| [GET /sapi/v1/equity/market/quote](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/market-data) | 用标的（如 MU，非 EQ_MU）查询。首版盘中按有效 USD 买卖报价中点估值，保留 bidPrice、askPrice、来源及观察时间，不当作成交价或正式收盘价。报价为空、非正或买卖倒挂时不估值。休市只可沿用该交易日历下最近已核验的收盘价并标明交易日；无此来源则保留股数、估值为 null。 |
| [GET /sapi/v1/equity/trade/history](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/trade) | 用 startTime、endTime 分窗，按 current、size 分页；同账号同 executionId 去重。买卖是账户内现金与股票互换，不是外部流入流出；成交历史只解释变化，不能再生成一份当前持仓。 |
| [GET /sapi/v1/equity/market/tokenized-assets](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/market-data) | **bStocks 待验证**：目录只说明产品映射，本次未匹配到非零余额。不能从标的股票反推出代币股数。若未来发现目录命中的原始钱包行，保留原钱包与正常余额口径，注明待验证，不并入美股类别或追加一笔折算资产。 |

同批同账号按钱包、原始资产代码统一明细键；两个资金接口都返回同一 EQ_ 资产时，股票以钱包余额明细为主，另一来源只对账。金额不一致则标待核对，不择大、不求和。按钱包聚合和按资产类别聚合分别读取同一组计入权益的明细。完整快照下，两组金额各自合计都等于 totalUsd；两个合计不能相加。

验收（虚构美元样例）：资金钱包现金价值 800，另有 2 股 EQ_MU、标的估值为每股 100，其他钱包均为零。钱包视图资金 = 1,000；类别视图美股 = 200（20%）、其他资产 = 800（80%）；总资产在两种视图均为 **1,000 USD**。即使另一资金接口也返回这 2 股或当日有买入成交，总额不变。若缺价，则保留 2 股，完整总额与占比为空，已估值小计为 800。

### 四组输入与预期结果
下例 BTC/USD = 60,000、USDT/USD = 0.998，均为虚构的同时点报价；下列四组均属同一账号。
1. 现货：`{"balances":[{"asset":"BTC","free":"0.08","locked":"0.02"}]}` → 0.10 BTC → **6,000 USD**。
2. 资金：`[{"asset":"USDT","free":"100","locked":"0","freeze":"0","withdrawing":"0"}]` → **99.80 USD**。如果另有非零在途且未核实，不沿用本例的完整状态。
3. 赚币：活期 `{"rows":[{"productId":"F1","asset":"USDT","totalAmount":"300","cumulativeTotalRewards":"7"}],"total":1}`，定期 `{"rows":[{"positionId":"12","asset":"USDT","amount":"200","status":"HOLDING"}],"total":1}` → **499 USD**，不是 507 USDT。
4. 合约：单资产模式 `{"assets":[{"asset":"USDT","walletBalance":"2000","unrealizedProfit":"200","marginBalance":"2200"}]}` → **2,195.60 USD**，即便有名义价值 20,000 的仓位也不增加权益。

上述四份完整快照合计 **8,794.40 USD**。环图按钱包 USD 权益除以同批选中账号的总权益；百分比仅展示时取整。权益为负、总额非正或覆盖不全时，列金额及原因，不画会误导的完整占比。

## 价格、时间与覆盖范围
每次采集冻结报价：优先采用带时间的直接 USD 报价；其次用币/USDT × USDT/USD，同一组 USD 汇率在同一批内复用。币/USDT 可取[币安现货行情](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#market-data-endpoints)；USDT/USD 需要独立的真实美元行情源，**上线条件**是选定可访问的提供方，验证交易对、时间戳及历史报价能力。未配置不出 USD 数值；不能把 1 USDT 写成 1 USD。仅 USD 自身以 1 计。盘中及连续交易资产的快照报价距观察时点最多 5 分钟；已核验休市收盘价按上述美股规则另行标记；事件估值用事件当时或之前 5 分钟内报价。历史无合格报价则缺价，不用当前价格补旧日。

保留成交或记账时刻、价格时刻、来源、转换路径。保留十进制，最终展示金额保留 2 位。可显示“已估值小计”，但它不是完整总资产。停用、刚接入、未开通、范围外和暂时无权限分别记录；组合只比较固定且已覆盖的账号集合，新增账号不算入金。

## 流水如何归类
| 来源（均为查询） | 用途 |
|---|---|
| [GET /sapi/v1/capital/deposit/hisrec、/sapi/v1/capital/withdraw/history](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/capital) | 仅结算成功的本金进入现金流；保存原始状态、到账时间、手续费及其币种。提取中不提前扣第二次。 |
| [GET /sapi/v1/asset/transfer](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/asset) | 按受支持的划转方向查询。同一选区内两端配对后本金抵销；跨到未跟踪钱包视为离开选区。 |
| [Simple Earn 活期、定期历史](https://developers.binance.com/en/docs/catalog/investment-and-services-simple-earn/api/rest-api/flexible-locked) | 分别查询 flexible 或 locked 下的 history/subscriptionRecord、redemptionRecord、rewardsRecord；申赎属钱包间移动，奖励属收益。 |
| [GET /fapi/v1/income](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account) | 按 incomeType 区分已实现盈亏、手续费、资金费、转账等。用于解释变化，不在期末权益上再次加总。 |

先保存各来源原记录，再按可核实的交易标识、网络、币种、方向和金额匹配；金额相同不是配对证据。同一划转在合约和钱包流水出现两次只生成一个业务事件。外部流量以实际交付本金为准，费用留在盈亏中。关联不确定、跨日仍在途、存在未覆盖的入金渠道（例如未接入的法币/C2C 记录）时，受影响区间的现金流与收益标未知；余额仍可独立展示。

## 每日指标：同一份数据服务曲线和日历
北京时间日界线按[同步约定](./同步流程与异常处理.md)取相邻完整边界权益 B、E。选区外部流 F 为各笔已确认现金流的带符号美元和，流入为正。资产变化 = E − B；盈亏 = E − B − F。账户内资金费、盈亏与奖励已经体现在权益里。多账号先确定选区，再计算现金流，不能把各账号收益率取平均。

真实日内流量按剩余时间加权（Modified Dietz 估算）：若一日长度 T，每笔流入或流出距日初 t，权重 w=(T−t)/T。日收益率 = 盈亏 ÷ (B + ΣwFᵢ)；分母非正、边界无效、流水不全或未定价，返回 null 和原因。区间收益率为逐日 (1+r) 连乘减一，任何一天缺失则不跨缺口复合。API 比率用小数，如 0.01 表示 1%。

验收：期初 10,000，中午入金 2,000，期末 11,900 → 变化 +1,900，盈亏 −100，收益率 −100/11,000 ≈ −0.91%。A 向 B 转 500，无费用无行情变化时，全选两账号的变化与盈亏均为 0；仅选 A 时变化 −500、净流入 −500、盈亏 0。同一日、同一选区的曲线提示值须与日历明细一致。
