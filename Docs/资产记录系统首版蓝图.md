# Bifrost 资产记录系统 · 首版蓝图

范围更新：2026-11-17｜状态：已确定首版范围，待实施

实现约定见[首版技术栈](./首版技术栈.md)：Go 负责定时同步；PostgreSQL 只存数据，不建外键。

## 目标与边界

一个人用只读 API 管理多个币安账号，在同一张表里看清每个账号的钱放在哪里，也能按日期回看当时持有的币、数量和价值。已确认的看板以 USD 展示估值，始终保留原币数量和原始计价单位；USDT 须按实际汇率折算。首版覆盖现货、资金、赚币（Simple Earn 活期和定期）及普通 U 本位合约账户。币安直接持有的美股纳入首版：钱包归属为资金账户，资产类别为「美股」。bStocks（股票代币）尚无非零余额样本，标为待验证，不归入直接持有的美股。

支持独立账号及持有各自密钥的币安子账号。首版不做母账号自动发现、交易下单或提币。ETH/SOL 质押、双币投资等其他赚币产品及统一账户不在首版估值范围；界面注明覆盖范围。记录保留交易所标识，方便后续接入其他交易所。

## 打开系统能看到什么

- **组合总览：** 每行一个账号，每列一个钱包，行末是账号合计，表底是钱包合计与组合总额。分布可切换「按钱包」和「按资产类别」；后者单列「美股」，两种视图使用同一批持仓。支持选择全部、单个或一组账号。首页展示已跟踪总资产、同一批账号的资产变化和已确认的外部净流入，不把余额涨幅称为投资收益率。收益曲线和日历按[资产口径](./资产口径与币安接口映射.md)扣除选区外部资金流。
- **资产明细：** 点开表格中的金额，可以查看对应账号的钱包余额、赚币产品或合约仓位。按币种回看时，分别展示数量和估值曲线，区分增持与涨价。
- **资金流水：** 按账号、钱包、币种、类型和时间筛选充提、划转、赚币申赎及奖励、合约已实现盈亏、资金费和手续费。保留来源、去向、状态及原始记录标识，方便核对。
- **账号管理：** 每个账号可独立命名、接入、手动刷新和更换密钥。密钥只存服务端；轮换密钥沿用同一账号历史，同一账号不能因接入两把密钥被重复汇总。

## 四类钱包如何计入总额

| 类别 | 保存的明细 | 计入规则 |
| --- | --- | --- |
| 现货 | 币种、可用数量、挂单锁定数量、估值价格 | 按可用与锁定数量之和估值；挂单不减少资产。 |
| 资金 | 各币种可用、锁定、冻结、提取中余额及钱包估值 | 资金美股按钱包原始代码（如 `EQ_MU`）保留股数，按标的 USD 报价估值。股票明细已在资金账户内，不能再加到资金小计或组合总额上。 |
| 赚币 | 活期按产品、定期按持仓记录币种、数量、状态及适用的到期日；另存申赎和奖励 | 按当前持仓估值。已发到现货或滚入活期的奖励不重复累加。 |
| U 本位合约 | 保证金币种、钱包余额、未实现盈亏、权益、可用余额；仓位另存交易对、方向、数量、开仓价和标记价 | 按账户模式和计价单位折算权益，组合只计一次。名义仓位、可用余额和已包含在权益中的浮盈均不另加。 |

例：合约钱包余额为 2,000 USDT、浮盈为 200 USDT，则计入总资产 2,200 USDT。即使对应仓位名义价值为 20,000 USDT，也不把它当成持有的现货。

## 多账号流水与历史比较

1. **按观察范围区分内外。** A 转到 B，单看 A 是流出，单看 B 是流入；如果同时跟踪 A 和 B，本金属于内部调拨，实际支付的手续费单列。保留两端原始记录，有可靠标识才关联，否则标为待确认。
2. **余额与流水分开。** 余额快照回答“当时有多少”，流水用于解释变化。钱包间划转或申购赚币不会凭空产生收益。相同来源记录重复同步只更新状态，不新记一笔。
3. **新增账号不制造收益。** 曲线标注账号纳入日期；区间变化只比较两端都有完整记录的同一组账号，展示实际参与比较的账号范围。

## 采集、估值与缺失数据

- 默认每 15 分钟采集一批快照，也支持手动刷新。按账号和钱包分别保存采集状态、采集时间及最近成功时间；数量、价格和估值按当时值保存，不用今天的价格改写历史。
- 只有确认余额为零才显示 0。未开通、无权限、同步失败分别显示；失败时保留上次成功值并注明时间，其他账号继续同步。含旧数据的总览明确标记，不生成看似完整的历史点。
- 无可靠价格时保留数量，标记“未估值”；汇总注明未计价项目，不将其价值视为零。
- 接入前按各接口可用范围补录，并标明来源和覆盖时间。币安每日账户快照只支持最近一个月内的部分账户类型，不能据此补齐四类资产。完整历史从首次可靠采集开始。

## 实施顺序与验收标准

| 阶段 | 交付 | 验收场景 |
| --- | --- | --- |
| 1. 核对当前资产 | 多账号只读接入、四类资产采集、总览表和明细 | 至少用两个账号与币安逐钱包、逐币核对；轮换密钥不重复计数；合约权益与仓位可分别查看。切换钱包/资产类别时总额不变，美股可从两种视图定位到同一持仓。 |
| 2. 留存可比较的历史 | 定时快照、历史明细、数量与估值曲线 | 能查出昨天某账号的 BTC 数量和当时估值；模拟新增账号、接口失败或缺价，不出现虚假涨跌。 |
| 3. 解释资金变化 | 充提和内部划转关联、申赎和奖励、合约损益流水 | 在价格不变且无费用时，现货转 500 USDT 到合约或申购等额活期，组合总额均不变；跨账号转账只计实际费用；重跑同步不重复记账。 |

## 币安官方接口参考

- [现货账户信息](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#account-information-user_data)：核对现货可用与锁定余额。
- [钱包资产](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/asset)：钱包余额、资金账户明细及万向划转历史；[充提记录](https://developers.binance.com/zh-CN/docs/catalog/core-trading-wallet/api/rest-api/capital)：核对充值、提币和状态。
- [美股目录与报价](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/market-data)、[股票成交历史](https://developers.binance.com/zh-CN/docs/catalog/advanced-trading-stocks-trading/api/rest-api/trade)：目录核验标的，成交解释变化，当前股数取自资金钱包明细。
- [Simple Earn 接口变更与记录字段](https://developers.binance.com/en/docs/products/simple-earn/change-log)：核对活期、定期持仓及申购、赎回和奖励字段。
- [U 本位合约账户及损益记录](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account)、[仓位信息](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/trade)：分别核对权益、损益流水及仓位。
- [每日账户快照](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/account)：接入前可补录的账户类型与历史范围。
