# 02: 安全绑定和维护只读账号

**What to build:** 在受保护的账号管理入口绑定只读凭据、轮换密钥和停用账号；只用模拟交易所身份完成开发验收。

**Blocked by:** 无

**Status:** done

验收条件（使用合成数据）：

- [x] 未认证不能管理账号；只有通过稳定交易所 UID 和只读权限核验才可激活，不能用别名或密钥哈希代替 UID。
- [x] 同一 UID 换钥前后内部账号标识一致，原有记录仍归同一账号；换成另一 UID 时拒绝覆盖。
- [x] 停用后拒绝新刷新，已有记录可查。凭据加密存储，响应和日志均不回显密钥或签名请求。

## 复现与验收

项目根目录运行 `./scripts/snapshot-demo.sh verify`，在全新临时 PostgreSQL 中执行 Go 套件。本票核心行为见 `internal/accounts/*_test.go`；单包测试可运行 `go test -v ./internal/accounts`（数据库用例需通过前述临时库脚本运行）。[多账号合成工作区](../../../README.md#运行多账号工作区)用于从页面核对。
