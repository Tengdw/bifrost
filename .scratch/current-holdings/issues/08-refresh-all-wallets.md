# 08: 一次刷新四个钱包，核对整批总额

**What to build:** 用户手动发起四钱包刷新，从同批总览追溯到各钱包原始持仓，辨别完整总额与部分成功。

**Blocked by:** 04, 05, 06, 07

**Status:** in-progress

验收条件（使用合成数据）：

- [ ] 合成四钱包估值为现货 6,000、资金 99.80、赚币 499、合约 2,195.60 USD；完整总额为 8,794.40 USD，明细与总览一致。
- [ ] 让一个钱包失败，其余三个仍可更新；列出失败原因、已估值小计，旧值标明时间，不拼成完整总额。
- [ ] 同批报价有效、应跟踪钱包均有有效观察且满足 2 分钟观察窗口才算完整；超窗不以新旧混合数据生成完整占比。
