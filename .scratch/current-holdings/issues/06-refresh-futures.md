# 06: 刷新 U 本位合约，分开显示权益和仓位

**What to build:** 展示普通 U 本位合约的保证金权益和独立的仓位明细，使用户能核对顺序和单位不同的两类数字。

**Blocked by:** 03

**Status:** in-progress

验收条件（使用合成数据）：

- [ ] 单资产模式按各结算币的保证金权益估值。合成样例中权益为 2,200 USDT，仓位名义价值为 20,000，后者不增加权益；浮盈也不再额外加一次。
- [ ] 联合保证金模式只计接口的 USD 汇总权益一次，保存并展示模式及计价单位。
- [ ] 统一账户标范围外；模式无法确认时给出原因，不按单资产模式估算。
