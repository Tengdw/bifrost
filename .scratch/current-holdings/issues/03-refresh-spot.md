# 03: 手动刷新现货，核对可用和锁定数量

**What to build:** 让用户对指定账号手动刷新现货，在明细查看采集时间和原币余额；建立后续钱包可复用的刷新入口。

**Blocked by:** 01, 02

**Status:** in-progress

验收条件（使用合成数据）：

- [ ] 合成响应含可用 0.08 BTC、锁定 0.02 BTC；保存后再查询，页面明细合计 0.10 BTC，不再额外加挂单占用。
- [ ] 同账号同钱包的请求在途时再次刷新，返回 already_running 和同一批次 ID，只发起一次采集。
- [ ] 仅刷新现货不能生成完整四钱包总额；无权限时显示原因，不保存成零余额。
