# 07: 让用户核对 USD 估值的来源和时间

**What to build:** 保存一批持仓所用的报价、时间与换算路径，让用户在明细中复核同批 USD 数值。

**Blocked by:** 01

**Status:** done

验收条件（使用合成数据）：

- [x] 优先使用合格的直接 USD 报价，否则使用币/USDT × USDT/USD；同批复用汇率。用合成汇率 0.998 验收，100 USDT 显示为 99.80 USD，刷新报价不改变既有快照。
- [x] 盘中股票使用有效美元买卖报价中点；连续交易或盘中报价距观察时点超过 5 分钟或无有效报价时保留数量并说明缺价原因。
- [x] 休市仅用已核验的最近收盘价并标明交易日；否则不估值。真实美元价源的交易对、时间戳和历史报价能力未经核验前，不启用实盘估值。

## 复现与验收

项目根目录运行 `./scripts/snapshot-demo.sh verify`，在全新临时 PostgreSQL 中执行 Go 套件。本票核心行为见 `internal/binance/*_test.go`；单包测试可运行 `go test -v ./internal/binance`（数据库用例需通过前述临时库脚本运行）。[多账号合成工作区](../../../README.md#运行多账号工作区)用于从页面核对。
