# 09: 切换两个账号，验证持仓隔离与组合汇总

**What to build:** 在最新采集页面切换 A、B、A+B，验证账号间持仓互不串用，组合估值只覆盖当前选区。

**Blocked by:** 03

**Status:** in-progress

验收条件（使用合成数据）：

- [ ] 用同批两个合成账号、同一现货币种及其余钱包确认零余额验收：A 的价值为 100 USD，B 为 250 USD，单选分别为 100、250，全选为 350；明细保留各自账号。
- [ ] 让 B 缺少一个应跟踪钱包的观察：单选 A 仍完整，A+B 只显示已估值小计和 B 的缺失原因，完整总额与占比为空。
- [ ] 筛选同时约束总览与明细；不依赖赚币或合约的真实采集，也不把另一账号的同币余额补入选区。
