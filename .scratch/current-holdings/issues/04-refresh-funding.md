# 04: 刷新资金钱包，核对现金和直接美股

**What to build:** 让资金余额与钱包股票明细进入同一次只读刷新，展示现金、股数及归属不确定的条目。

**Blocked by:** 03

**Status:** done

验收条件（使用合成数据）：

- [x] 以合成输入验证：Funding 的 EQ_MU 与股票目录完整匹配后按直接美股展示；两个来源均返回 2 股仍只计一次，同名裸代码不自动分类为股票。
- [x] 两来源数量不一致、股票明细未返回，或非零冻结及在途字段未核实互斥时，保留可核对数据并说明原因，不报完整总额。
- [x] bStocks 按原钱包记录并标待验证，不推算成直接持股。

## 复现与验收

项目根目录运行 `./scripts/snapshot-demo.sh verify`，在全新临时 PostgreSQL 中执行 Go 套件。本票核心行为见 `internal/binance/*_test.go`；单包测试可运行 `go test -v ./internal/binance`（数据库用例需通过前述临时库脚本运行）。[多账号合成工作区](../../../README.md#运行多账号工作区)用于从页面核对。
